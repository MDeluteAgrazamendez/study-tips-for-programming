# Study tips for Programming

A beginner-friendly guide for students who want to improve their programming skills through effective study habits

## Helpful Learning Resources

- W3Schools - Beginner Programming tutorials and examples.
- Programiz - tutorials and explanations for learning python
- GitHub Docs - Learning Git and Github
- freeCodeCamp - Programming Lessons and exercises

## Git Best Practices

- Commit your changes regularly.
- Use clear commit messages.
- Create branches when working on new features.
- Review changes before merging.
- Communicate with your teammates.
- Pull the latest changes before starting new work.
